StyleBook - Developer Manual & Engineering Guide v2.0

Local Environment Setup, Project Structure, Debugging Microservices & Database Workflow

1. Development Prerequisites

  • .NET 8.0 SDK: dotnet --version (8.0.x or higher)
  • Node.js: v18.17.0 LTS or v20.x
  • PostgreSQL: v15 or v16 (running locally on port 5432, database: stylebook_db)
  • Docker & Docker Compose: (Optional for containerized mode)
  • IDE: Visual Studio 2022 (v17.8+) or Visual Studio Code with C# DevKit & React extensions

3. Local Orchestration Scripts

The project provides automated scripts to start and stop all microservices and web apps simultaneously:

Start All Services:

C:\Users\ayesh\Desktop\Mahathir\Projects\StyleBook\run-all.bat

This script checks prerequisites, verifies PostgreSQL connectivity, launches each .NET microservice in a dedicated process window, and starts both Vite and Next.js frontend dev servers.

Stop All Services:

C:\Users\ayesh\Desktop\Mahathir\Projects\StyleBook\stop-all.bat

Gracefully terminates all background dotnet processes, node workers, and frees ports 5000-5006, 3000, and 3001.

4. How to Debug an Individual Microservice

If you need to set breakpoints in a single service (e.g., StyleBook.Booking.Api):

  1. Open terminal in the project root: 
    cd src\Services\Booking\StyleBook.Booking.Api
dotnet run --launch-profile "http"
  2. Attach the Visual Studio or VS Code debugger to the running process.
  3. Send requests through the API Gateway on port 5000 or directly on port 5004 to inspect EF Core execution and slot calculation variables.

5. Adding a New Database Entity or Migration

  1. Create the entity class inside src\BuildingBlocks\StyleBook.Shared\Domain\Entities\.
  2. Register the DbSet<T> inside StyleBookDbContext.cs.
  3. Configure any relational mappings (keys, foreign keys, decimal precision) in OnModelCreating.
  4. Add the corresponding table DDL inside database\init.sql.
  5. Inject IRepository<T> into your Minimal API endpoints or Controllers to perform queries.
