Zero-to-Hero Quickstart: Database Seeding, One-Click Orchestration, Demo Accounts & Walkthrough Script

1. Step-by-Step Initial Environment Setup

1 Verify Prerequisites

Open a PowerShell terminal and verify that .NET 8, Node.js, and PostgreSQL are installed:

dotnet --version      # Expected: 8.0.x
node -v               # Expected: v18.x or v20.x
psql -U postgres -c "SELECT version();"

2 Create and Seed Database

Create the stylebook_db database in PostgreSQL and run the seed script:

# Open PostgreSQL command line
psql -U postgres -c "CREATE DATABASE stylebook_db;"

# Execute initialization and seed script
psql -U postgres -d stylebook_db -f "C:\Users\ayesh\Desktop\Mahathir\Projects\StyleBook\database\init.sql"

3 Restore Dependencies

# Restore .NET Solution
cd C:\Users\ayesh\Desktop\Mahathir\Projects\StyleBook
dotnet restore StyleBook.sln

# Install Management Portal packages
cd src\Web\stylebook-management
npm install

# Install Customer Web packages
cd ..\stylebook-customer
npm install

4 Launch All Services via Orchestration Script

Run the automated batch script to launch the Gateway, all microservices, and both web frontends in separate console windows:

cd C:\Users\ayesh\Desktop\Mahathir\Projects\StyleBook
.\run-all.bat

Wait approximately 15 seconds for all services to initialize. You will see green status messages confirming healthy ports.

3. First-Time Walkthrough Script (Verifying the Complete Flow)

Phase 1: Inspection & Approval as Zonal Manager

  1. Open browser at http://localhost:3000.
  2. Login using zonal_ramnad / Zone@12345.
  3. Navigate to "Pending Salons" tab. You will see "Sakkarakottai Heritage Salon" under review.
  4. Click "Review Documents & Approve". The salon immediately transitions to Approved and becomes live on the marketplace.

Phase 2: Booking an Appointment as Customer

  1. Open http://localhost:3001 in a new browser window.
  2. Browse trending salons in Ramanathapuram or filter by locality chip "Ramnad Town".
  3. Click on "Royal Classic Unisex Salon & Spa" → Select "Haircut & Styling" (₹200) + "Herbal Hair Spa" (₹700).
  4. Select Stylist "Karthik Raja" & choose a tomorrow slot at 11:00 AM.
  5. Apply promo code RAMNAD50 for flat ₹50 OFF. Net payable = ₹850.
  6. Choose "Pay at Salon (Cash)" or "Pay Online" and confirm.
  7. The system displays your booking confirmation with a secure **6-digit Arrival OTP** (e.g. 849201).

Phase 3: Arrival Check-In & Service Completion

  1. Switch back to the Management app at http://localhost:3000.
  2. Switch user / login as karthik_stylist or owner_royalclassic.
  3. Navigate to "Today's Appointments". Find the booking reference.
  4. Click "Verify OTP & Start Service" & enter 849201.
  5. Status updates to In-Progress. Upon completion, click "Complete Appointment".
  6. The system auto-calculates commission:
    • Debits commission from Owner Wallet if cash, or credits net earnings to Owner Ledger if online.

Phase 4: Customer Review Submission

  1. Refresh the Customer page at http://localhost:3001 under "My Bookings".
  2. Click "Leave Review".
  3. Submit 5 stars for the Branch and 5 stars for Stylist Karthik with written feedback.
  4. Verify that the rating updates dynamically on the public salon and stylist profiles.
