2. Microservices Network & Port Reference

Service Protocol / Port Primary Endpoints Responsibilities
API Gateway HTTP / 5000 /api/* Ocelot reverse proxy, CORS aggregation, centralized routing.
Identity Service HTTP / 5001 /api/auth/login, /api/auth/users JWT authentication, downward user provisioning, territorial role scoping.
Master Data Service HTTP / 5002 /api/master/geographies, /api/master/services Geographic tiers (Country → State → Zone → District), Minimum Floor Prices.
Salon Service HTTP / 5003 /api/salons/branches, /api/salons/notices Branch creation, Stylist multi-skill onboarding, Branch transfers, Targeted notices.
Booking Service HTTP / 5004 /api/bookings, /api/bookings/reviews Real-time slot reservation, 6-Digit OTP check-in, Dual review and rating engine.
Management Portal HTTP / 3000 Vite Dev / Prod Enterprise management dashboard with downgrade user creation and governance.
Customer Portal HTTP / 3001 Next.js 14 SSR/SSG Smart search, horizontal carousels, Two Booking Entry Points, and Dual Reviews.

3. Dual Review API Specification

Endpoint: POST /api/bookings/reviews

Request Body:

{
  "bookingId": "SB-RAMNAD-01",
  "branchId": "b1",
  "branchRating": 5,
  "branchComment": "Clean premises and punctual slots in Ramnad Town.",
  "stylistId": "s1",
  "stylistRating": 5,
  "stylistComment": "Karthik did a fantastic haircut with precision scissors work.",
  "customerName": "Mohamed Irfan"
}

Validation Logic:

  • Verifies that the target booking exists and is in Completed status.
  • Checks PostgreSQL booking.reviews for existing booking_id to prevent duplicates.
  • Ensures both branchRating and stylistRating are integers between 1 and 5.

4. Targeted Compliance Notices Architecture

Compliance notices are scoped to specific operational recipients:

  • target_type = 'STYLIST': Delivered to individual stylists (e.g. shift notice or certification renewal).
  • target_type = 'OWNER': Delivered to salon shop owners (e.g. audit requirement or licensing).
  • target_type = 'BRANCH': Delivered to branch operations managers (e.g. facility inspection).
  • target_type = 'CUSTOMER': Displayed prominently on customer landing page banner.
