StyleBook Platform - Technical Implementation Document

This document details the concrete technical implementation of the StyleBook enterprise salon and grooming platform, covering .NET 8 Clean Architecture microservices, Ocelot Gateway, PostgreSQL database schemas, React JSX management portal, Next.js customer web, and mobile app.

1. Microservices Architecture & Solution Structure

The system is built as a set of decoupled, specialized microservices fronted by an Ocelot API Gateway. Persistence is managed in PostgreSQL using dedicated domain schemas:

  • API Gateway (Port 5000): Ocelot Gateway routing requests, enforcing JWT policies, and centralizing CORS.
  • Identity Service (Port 5001): JWT issuance, login authentication, user roles, hierarchical RBAC downgrade provisioning, and territorial allocation link tables.
  • Master Data Service (Port 5002): Multi-region hierarchy (Countries, States, Zones, Districts), service categories, Master Services catalog with Minimum Floor Price authority.
  • Salon Service (Port 5003): Salon onboarding, multi-branch mapping (Country → State → Zone → District), Active/DeActive toggles, stylist skill multi-select, branch transfers, and targeted compliance notices (STYLIST, OWNER, BRANCH, CUSTOMER).
  • Booking Service (Port 5004): Dynamic slot calculation engine, 6-digit OTP verification, coupon code deduction, price bargaining, and dual review & rating submission (Branch + Stylist).
  • Marketing Service (Port 5005): Platform B2B owner incentives and targeted customer announcements.
  • Management & Owner Web (Port 3000): React.js JSX + Vite with mandatory login, hierarchical user provisioning (strictly downgrade users), branch/stylist active-deactive toggles, OTP start verification, shift adjustment, and POC directory.
  • Customer Web (Port 3001): Next.js App Router with Smart Global Search, horizontally scrollable carousels, Two Booking Entry Points (Choose Branch vs Choose Stylist), and Dual Reviews.
  • Mobile Application: Cross-platform React Native / Expo pocket client.

2. PostgreSQL Database Schema Implementation

The database architecture is cleanly segmented across domain schemas in stylebook_db:

-- 1. Dual Review & Rating Schema with Booking Uniqueness
CREATE TABLE IF NOT EXISTS booking.reviews (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    booking_id VARCHAR(50) NOT NULL UNIQUE,
    branch_id VARCHAR(50),
    branch_rating INT CHECK (branch_rating BETWEEN 1 AND 5),
    branch_comment TEXT,
    stylist_id VARCHAR(50),
    stylist_rating INT CHECK (stylist_rating BETWEEN 1 AND 5),
    stylist_comment TEXT,
    customer_name VARCHAR(100),
    is_moderated BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 2. Targeted Governance & Compliance Notices
CREATE TABLE IF NOT EXISTS salon.compliance_notices (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    title VARCHAR(200) NOT NULL,
    description TEXT NOT NULL,
    notice_type VARCHAR(50) NOT NULL,
    target_type VARCHAR(50) NOT NULL, -- 'STYLIST', 'OWNER', 'BRANCH', 'CUSTOMER'
    target_id VARCHAR(50),
    target_name VARCHAR(150),
    severity VARCHAR(20) DEFAULT 'Warning',
    deadline TIMESTAMP WITH TIME ZONE,
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 3. Master Services with Minimum Floor Price
CREATE TABLE IF NOT EXISTS master.services (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    category_id UUID REFERENCES master.service_categories(id),
    name VARCHAR(100) NOT NULL,
    base_price DECIMAL(10, 2) NOT NULL,
    minimum_floor_price DECIMAL(10, 2) NOT NULL DEFAULT 100.00,
    duration_minutes INT NOT NULL,
    is_active BOOLEAN DEFAULT TRUE
);

-- 4. Multi-Region Geographies (Global Scalability)
CREATE TABLE IF NOT EXISTS master.countries (
    id VARCHAR(50) PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    code VARCHAR(10) NOT NULL
);

CREATE TABLE IF NOT EXISTS master.states (
    id VARCHAR(50) PRIMARY KEY,
    country_id VARCHAR(50) REFERENCES master.countries(id),
    name VARCHAR(100) NOT NULL
);

CREATE TABLE IF NOT EXISTS master.zones (
    id VARCHAR(50) PRIMARY KEY,
    state_id VARCHAR(50) REFERENCES master.states(id),
    name VARCHAR(100) NOT NULL
);

CREATE TABLE IF NOT EXISTS master.districts (
    id VARCHAR(50) PRIMARY KEY,
    zone_id VARCHAR(50) REFERENCES master.zones(id),
    name VARCHAR(100) NOT NULL
);

3. Customer Web: Smart Search & Dynamic Discovery

Smart Global Search Box

The unified search box uses an in-memory or indexed relational query that matches against:

  • Brand Name: e.g., Royal Classic, Kavitha Beauty Studio.
  • Salon / Branch Name: e.g., Ramnad Town Branch, Puduvalasai Branch.
  • Stylist Name: e.g., Karthik Raja, Kavitha Praveen, Saravanan Natarajan.
  • Location: Country (India), State (Tamil Nadu), District (Ramanathapuram), Zone (South Zone), Locality (Ramnad Town, Puduvalasai, Panaikulam, Sakkarakottai).
  • Service Name & Category: Haircut, Herbal Hair Spa, Hot Towel Shave, Bridal Makeover, Facial & Glow, Head Massage.

Dynamic Horizontally Scrollable Carousels

Implemented via responsive flex layouts with smooth scrollSnapType: 'x mandatory':

  • Trending Salons: Highlighting certified multi-branch shops with overall rating and doorstep badges.
  • Top-Rated Branches: Direct entry point into branch profile and branch-only services.
  • Popular Services: Instant service cards with pricing, duration, and floor-price bargain chip.
  • Top-Rated Stylists: Personal stylist cards with bio, skill tags, rating, and direct booking trigger.
  • Doorstep Specialists: Filtered views for certified mobile beauticians visiting customer homes.

4. Two Booking Entry Points & Relational Validation

Entry Point 1: Choose a Branch (Branch-First Booking)

  1. Customer selects branch → Loads branch profile and contact information.
  2. Service selection displays only services offered at that branch.
  3. Stylist selection displays stylists assigned to that branch who can perform the selected service, PLUS an "Any Available Stylist" option.
  4. Confirmation Rule: If "Any Stylist" is chosen, confirmation is handled by the Owner who assigns the stylist. If a specific stylist is chosen, confirmation is executed by that stylist or the owner.
  5. Selects Date & Time Slot → Reviews Pricing & Coupons → Confirms Booking → Generates 6-Digit OTP.

Entry Point 2: Choose a Stylist (Stylist-First Booking)

  1. Customer selects stylist → Loads stylist profile, experience, and certifications.
  2. Service selection displays only services certified for that stylist.
  3. Branch selection displays only branches where that stylist is actively assigned.
  4. Selects Service Mode (In-Salon vs Doorstep) → Date & Slot → Reviews Pricing & Coupons → Confirms Booking.

5. Dual Customer Review & Rating System

Completed appointments trigger the dual review form allowing customers to evaluate both dimensions:

Review Dimension Rating Scale Evaluation Scope
Salon Branch 1 to 5 Stars Hygiene, ambiance, punctuality, equipment, seating, and comfort.
Stylist 1 to 5 Stars Skill, cutting precision, consultation, friendliness, and styling result.
Fraud Protection: Submissions are bound to booking_id via a database UNIQUE constraint, preventing duplicate reviews for the same appointment.

6. Territorial RBAC & Downgrade User Provisioning

User provisioning enforces strict downward hierarchy: higher roles can only provision lower roles:

  • Super Admin (Level 1): Can create Countries and provision State Admins (Level 2), Zonal Managers (Level 3), Owners (Level 4), Stylists (Level 5).
  • State Admin (Level 2): Can create States, Zones, Districts and provision Zonal Managers (Level 3), Owners (Level 4), Stylists (Level 5) in their state.
  • Zonal Manager (Level 3): Can provision Owners (Level 4) and Stylists (Level 5) in their zone. Approves/rejects salons and manages Active/DeActive status.
  • Salon Owner (Level 4): Can onboard branches, multi-select stylist skills, transfer stylists between branches, assign stylists for bookings, and manage shift schedules.
  • Stylist (Level 5): Can select/deselect personal services (skills), request shift adjustments, and verify 6-digit OTPs.
