2. Microservices Network & Ocelot Gateway Routing

All external traffic flows through the Ocelot Gateway on http://localhost:5000:

Upstream Path (Gateway URL) Downstream Microservice Downstream Port Supported Methods

/api/auth/*, /api/users/* StyleBook.Identity.Api 5002 GET, POST, PUT
/api/salons/*, /api/branches/*, /api/stylists/* StyleBook.Salon.Api 5003 GET, POST, PUT, DELETE

3. Core C# Entity Definitions in StyleBook.Shared

Domain entities are unified in StyleBook.Shared.Domain.Entities for EF Core:

// Example: Booking Financial Split Model for Accounting
namespace StyleBook.Shared.Domain.Entities
{
    public class BookingFinancialSplit
    {
        public Guid BookingId { get; set; }
        public string PaymentMode { get; set; } = "ONLINE_ESCROW"; // or PAY_AT_SALON_CASH
        public decimal GrossCustomerPaid { get; set; }
        public decimal SalonDiscountAmount { get; set; }
        public decimal PlatformCouponDiscount { get; set; }
        public decimal NetServiceAmount { get; set; }
        public decimal CommissionPercentage { get; set; }
        public decimal PlatformCommissionAmount { get; set; }
        public decimal PlatformCommissionGst { get; set; }
        public decimal TdsWithheldAmount { get; set; }
        public decimal OwnerNetPayable { get; set; }
        public string SettlementStatus { get; set; } = "PENDING_COMPLETION";
        public DateTime? SettledAt { get; set; }
    }
}

4. Web Frontend Architecture

4.1 Management Portal (`stylebook-management`)

  • Built with **React 18 + Vite** for instant HMR.
  • Contains viewports tailored to role:
    • Super Admin: System health, master geographies, global pricing floor.
    • Zonal Manager: Onboarding verification, branch approvals queue, compliance notices.
    • Finance Officer: Subscriptions, commissions, wallet ledger, automated payout triggers.
    • Salon Owner: Branch manager, stylist mapper, calendar roster, earnings ledger.

4.2 Customer Portal (`stylebook-customer`)

  • Built with **Next.js 14 App Router** for server-side rendering and high SEO visibility.
  • Features landing page discovery with locality filters (Ramnad, Puduvalasai, Panaikulam, Sakkarakottai).
  • Two entry flows: Branch-First & Stylist-First.
  • Integrated slot reservation, coupon redemption, 6-digit OTP modal, and dual rating forms.
