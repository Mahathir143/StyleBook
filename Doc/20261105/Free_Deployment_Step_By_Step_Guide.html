Step 1: Create Free PostgreSQL Database on Neon.tech (3 Minutes)

Step 1.1 Sign Up & Create Project
  1. Go to https://neon.tech and click "Sign in with GitHub".
  2. Click "Create a project":
    • Project Name: stylebook-db
    • Region: Select AWS / Asia Pacific (Singapore) or closest to you.
    • PostgreSQL Version: 16.
  3. Click "Create project".
Step 1.2 Execute Schema Initialization (`database/init.sql`)
  1. In your Neon dashboard sidebar, click "SQL Editor".
  2. Open the file on your machine:
    C:\Users\ayesh\Desktop\Mahathir\Projects\StyleBook\database\init.sql
  3. Copy the entire content of init.sql, paste it into Neon's SQL Editor, and click "Run".
  4. Verify: Neon will confirm that schemas (master, identity, salon, booking, billing, accounting) and seed data were created successfully!
Step 1.3 Copy Connection String

On your Neon project dashboard, copy the Connection string (Select .NET or Connection String):

Host=ep-cool-butterfly-123456.ap-southeast-1.aws.neon.tech;Database=neondb;Username=stylebook_owner;Password=YOUR_SECRET_PASSWORD;SSL Mode=Require;Trust Server Certificate=true;

Save this connection string—you will paste it into Render in Step 2!

Step 2: Deploy Backend & Ocelot Gateway on Render.com (5 Minutes)

Step 2.1 Connect GitHub to Render
  1. Go to https://render.com and log in with your GitHub account.
  2. On the Render dashboard, click "New +" → "Web Service".
  3. Select "Build and deploy from a Git repository" & click Next.
  4. Choose your repository: Mahathir143/StyleBook.
Step 2.2 Configure Web Service
  • Name: stylebook-api
  • Region: Singapore (Southeast Asia) or closest.
  • Runtime: Docker (Render will automatically detect our root Dockerfile!).
  • Instance Type: Free ($0/month).
Step 2.3 Add Database Environment Variable

Scroll down to "Environment Variables" and add:

Key Value
ConnectionStrings__DefaultConnection (Paste your Neon connection string from Step 1.3)
ASPNETCORE_ENVIRONMENT Production
Step 2.4 Deploy

Click "Create Web Service". Render will build the Docker container and start all 5 microservices and the Ocelot Gateway.

Once built, you will get your live backend URL:
https://stylebook-api.onrender.com

Step 3: Deploy Customer Web App on Vercel (2 Minutes)

  1. Go to https://vercel.com and log in with GitHub.
  2. Click "Add New..." → "Project".
  3. Import Mahathir143/StyleBook.
  4. In Root Directory: Click Edit and select:
    src/Web/stylebook-customer
  5. Framework Preset: Next.js.
  6. (Optional) In Environment Variables, add:
    NEXT_PUBLIC_API_URL = https://stylebook-api.onrender.com
  7. Click "Deploy".
  8. Live URL: https://stylebook-customer.vercel.app

Step 4: Deploy Management Portal on Vercel (2 Minutes)

  1. On Vercel, click "Add New..." → "Project".
  2. Import the same repo: Mahathir143/StyleBook.
  3. In Root Directory: Click Edit and select:
    src/Web/stylebook-management
  4. Framework Preset: Vite.
  5. Build Command: npm run build • Output Directory: dist.
  6. Click "Deploy".
  7. Live URL: https://stylebook-management.vercel.app
