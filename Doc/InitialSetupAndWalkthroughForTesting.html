StyleBook - Setup & End-to-End Testing Walkthrough

This guided document provides step-by-step instructions for launching, testing, and verifying the StyleBook ecosystem configured for Tamil Nadu & Ramanathapuram District with two booking entry points, dynamic carousels, dual reviews, hierarchical RBAC, governance notices, and site POCs.

1. Prerequisites & Environment

  • PostgreSQL 14+ running on localhost:5432 (User: postgres, Password: 12345678, Database: stylebook_db).
  • .NET 8 SDK installed (verify via dotnet --version).
  • Node.js 18+ & npm installed (verify via node -v).

2. One-Click Launch (`run-all.bat`) & Cleanup (`stop-all.bat`)

1Start All Services in Coordinated Dependency Order:

cd C:\Users\ayesh\Desktop\Mahathir\Projects\StyleBook
run-all.bat

The runner executes a coordinated launch sequence:

  1. Port Conflict Guard: Scans and terminates any stale processes holding ports 5000-5005, 3000, or 3001.
  2. Database Connectivity Check: Validates PostgreSQL connection and schema availability.
  3. Sequential Service Startup: Starts Identity (5001) → MasterData (5002) → Salon (5003) → Booking (5004) → Marketing (5005) → Ocelot API Gateway (5000) → Management Web (3000) → Customer Web (3001).

Clean Shutdown:

Press Q or [Enter] in the main runner window to terminate all spawned child processes. Alternatively, run stop-all.bat at any time to release all ports immediately.

4. Testing Two Booking Entry Points (Customer Web: Port 3001)

2Test Entry Point 1: Choose by Branch

  1. Open http://localhost:3001. Scroll to the Top-Rated Salon Branches carousel.
  2. Click "Book at this Branch" on Royal Classic - Ramnad Town Branch.
  3. Notice that service selection shows only the services offered at this branch.
  4. Stylist selection shows assigned stylists plus "Any Available Stylist". Select "Any Stylist".
  5. Select Date and available slot (e.g., 02:00 PM - 02:30 PM).
  6. Apply coupon RAMNAD50 (saves ₹50) and click "Confirm & Get 6-Digit OTP".
  7. Verify generated 6-digit check-in OTP and note the booking status: Owner Assignment Pending.

3Test Entry Point 2: Choose by Stylist

  1. On http://localhost:3001, scroll to the Top-Rated Stylists & Beauticians carousel.
  2. Click "Book with Karthik" on Karthik Raja's card.
  3. Observe that the service selection displays only services certified for Karthik (Haircut, Hair Spa, Shave, Beard, Facial).
  4. Branch selector displays only eligible branches where Karthik works (Ramnad Town & Puduvalasai).
  5. Confirm the appointment and receive your instant 6-digit arrival OTP with direct stylist confirmation.

5. Testing Dual Reviews & Duplicate Prevention

4Submit Dual Experience Feedback:

  1. Click your customer name in the top right menu and open "My History & Reviews".
  2. Locate the completed appointment (SB-RAMNAD-99) and click "⭐ Leave Review / Rate".
  3. Provide separate star ratings (1 to 5) and written feedback for:
