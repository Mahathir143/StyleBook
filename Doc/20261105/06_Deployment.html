StyleBook - Production Deployment Manual v2.0

Zero-Downtime Deployment: Docker Compose, AWS / Azure Architecture, Nginx SSL Reverse Proxy & Database Tuning

1. Production Topology Options

StyleBook is designed to run under two production topologies:

  1. Single Virtual Server (VPS / EC2 / Azure VM): Co-located Docker Compose stack running PostgreSQL, Ocelot Gateway, all .NET microservices, and static Web frontends behind an Nginx SSL reverse proxy. Cost-effective for regional launches.
  2. Enterprise Cloud Native (AWS / Azure):
    • Database: Managed PostgreSQL (AWS RDS Multi-AZ or Azure Database for PostgreSQL Flexible Server).
    • Containers: AWS ECS Fargate or Azure Container Apps with autoscaling.
    • Media Storage: AWS S3 / Azure Blob Storage with CDN edge caching for salon photos.
    • Load Balancer: AWS ALB or Azure Application Gateway managing TLS 1.3 termination.

2. Step-by-Step Production Deployment via Docker Compose

Follow these steps to deploy on an Ubuntu 22.04 LTS / 24.04 LTS production server:

Step 2.1: Server Hardening & Dependency Setup

# Update OS packages
sudo apt update && sudo apt upgrade -y

# Install Docker & Compose plugin
sudo apt install -y ca-certificates curl gnupg lsb-release
sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt update && sudo apt install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin

# Enable Docker on startup
sudo systemctl enable docker && sudo systemctl start docker

Step 2.2: Clone Project & Configure Production Environment

git clone https://github.com/your-org/StyleBook.git /var/www/stylebook
cd /var/www/stylebook

# Create production .env file
cat < .env
POSTGRES_USER=stylebook_admin
POSTGRES_PASSWORD=YourStrongSuperSecretPassword2026!
POSTGRES_DB=stylebook_db
JWT_SECRET=StyleBookSuperSecureJWTKeyWith256BitEncryptionForAuth2026!
ASPNETCORE_ENVIRONMENT=Production
EOF

Step 2.3: Build & Launch Stack

# Pull dependencies and build optimized Docker images
docker compose -f docker-compose.yml up -d --build

# Verify all containers are healthy
docker compose ps

3. Production Nginx Reverse Proxy with SSL (Certbot)

Install and configure Nginx to route traffic to the customer web app, management portal, and API Gateway:

server {
    listen 80;
    server_name stylebook.in admin.stylebook.in api.stylebook.in;
    return 301 https://$host$request_uri;
}

# Customer Portal (stylebook.in)
server {
    listen 443 ssl http2;
    server_name stylebook.in;

    ssl_certificate /etc/letsencrypt/live/stylebook.in/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/stylebook.in/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:3001;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

# Management Portal (admin.stylebook.in)
server {
    listen 443 ssl http2;
    server_name admin.stylebook.in;

    ssl_certificate /etc/letsencrypt/live/stylebook.in/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/stylebook.in/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

# API Gateway (api.stylebook.in)
server {
    listen 443 ssl http2;
    server_name api.stylebook.in;

    ssl_certificate /etc/letsencrypt/live/stylebook.in/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/stylebook.in/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

4. Database Backup & Disaster Recovery Automation

Setup a nightly cron backup for PostgreSQL with 30-day retention and S3 sync:

# /etc/cron.daily/backup-stylebook-db
#!/bin/bash
BACKUP_DIR="/var/backups/stylebook"
TIMESTAMP=$(date +"%Y%m%d_%H%M%S")
mkdir -p $BACKUP_DIR

docker exec stylebook-db pg_dump -U stylebook_admin stylebook_db | gzip > $BACKUP_DIR/db_$TIMESTAMP.sql.gz

# Retain only last 30 days locally
find $BACKUP_DIR -type f -name "*.sql.gz" -mtime +30 -delete

# Sync to secure S3 bucket
aws s3 sync $BACKUP_DIR s3://stylebook-database-backups/prod/
