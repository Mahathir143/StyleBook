StyleBook Platform - Cloud Deployment Guide & Client Demo Strategy

This technical and strategic guide outlines deployment pathways for Free-Tier Cloud Services (Zero-Cost Prototyping) and Enterprise Paid Cloud Infrastructures (AWS / Azure), followed by a turnkey demonstration strategy to pitch StyleBook to salon owners, zonal authorities, and end-customers.

1. Free Cloud Deployment Strategy (Zero-Cost Live Preview)

For live staging, customer previews, and portfolio presentations without incurring cloud bills, deploy the architecture across these production-grade free-tier platforms:

PostgreSQL Database Supabase or Neon.tech 500MB storage, unlimited read/write within limits, pooled connections Direct import of database/init.sql via web SQL console
Customer Web (Next.js) Vercel 100GB bandwidth/month, instant global edge CDN, automatic HTTPS Link GitHub repo Mahathir143/StyleBook (Root: src/Web/stylebook-customer)

Step-by-Step Free Tier Setup:

1. Database Setup on Neon / Supabase:
  1. Create a free PostgreSQL instance on Neon.tech or Supabase.com.
  2. Copy the PostgreSQL connection string: Host=ep-xxx.neon.tech;Database=stylebook_db;Username=xxx;Password=xxx;SSL Mode=Require;
  3. Open the SQL Editor and run the full database/init.sql script to populate schemas, tables, and Tamil Nadu regional seeds.
2. Customer Portal on Vercel:
  1. Sign in to Vercel with your GitHub account (Mahathir143).
  2. Select Import Git Repository → Choose StyleBook.
  3. Set Root Directory to src/Web/stylebook-customer.
  4. Click Deploy. Vercel automatically produces a live URL (e.g. https://stylebook-customer.vercel.app).
3. Management Portal on Cloudflare Pages / Netlify:
  1. On Cloudflare Pages, choose Create Project → Connect to Git.
  2. Set Root directory: src/Web/stylebook-management.
  3. Build command: npm run build, Build output directory: dist.
  4. Deploy to obtain a live URL (e.g. https://stylebook-management.pages.dev).

2. Paid Enterprise Cloud Deployment (AWS & Azure Production Architecture)

For multi-region production, high concurrency, and SLA guarantees, deploy StyleBook on enterprise hyperscalers:

A. Amazon Web Services (AWS) Architecture

  • Database: Amazon RDS for PostgreSQL (Multi-AZ with automatic failover and read-replicas).
  • Compute / Microservices: AWS ECS Fargate (serverless containers) or AWS Elastic Kubernetes Service (EKS) orchestrated via Helm charts.
  • API Gateway: AWS Application Load Balancer (ALB) fronting the Ocelot Gateway container on Port 5000.
  • Frontend Hosting: AWS S3 Static Website Hosting + CloudFront CDN + Route 53 DNS with free ACM SSL certificates.
  • Secrets & Configuration: AWS Secrets Manager and Systems Manager Parameter Store.

B. Microsoft Azure Architecture

  • Database: Azure Database for PostgreSQL - Flexible Server with Zone Redundant High Availability.
  • Compute / Microservices: Azure Container Apps (serverless, microservices-native with built-in Dapr and KEDA scaling).
  • API Gateway: Azure API Management (APIM) or Azure Application Gateway with Web Application Firewall (WAF).
  • Frontend Hosting: Azure Static Web Apps with global edge distribution and automated GitHub Actions CI/CD workflows.
  • Security: Azure Key Vault storing JWT signing keys and database connection strings.

CI/CD Pipeline via GitHub Actions (.github/workflows/deploy.yml)

name: Build and Deploy StyleBook

on:

    branches: [ main ]

jobs:
  build-and-test:

    steps:
      - uses: actions/checkout@v3
      - name: Setup .NET 8
        uses: actions/setup-dotnet@v3
        with:
          dotnet-version: 8.0.x
      - name: Build Backend
        run: dotnet build StyleBook.sln --configuration Release
      - name: Build Management Web
        run: |
          cd src/Web/stylebook-management
          npm ci
          npm run build
      - name: Build Customer Web
        run: |
          cd src/Web/stylebook-customer
          npm ci
          npm run build

3. Client & Customer Demonstration Strategy ("What Can We Do Next?")

Here is an actionable, high-impact demonstration playbook designed to showcase the platform to Salon Shop Owners, Zonal / Franchise Investors, and End Customers:

A. Live Pitch Script for Salon Shop Owners (B2B)

  • The No-Show Solution: Demonstrate how the 6-digit arrival OTP eliminates fraudulent bookings and guarantees real revenue.
  • Zero Staff Confusion: Show how the Owner exclusively confirms and assigns staff for "Any Stylist" requests, maintaining full operational control.
  • Shift & Roster Flexibility: Demonstrate how stylists request time adjustments in the portal without disrupting customer bookings.
  • Floor Price Protection: Show that customer price bargaining cannot violate the salon's minimum threshold (e.g. minimum ₹550 floor on ₹700 Herbal Spa).
  • Dual Reviews Fairness: Explain that customer reviews evaluate premises and individual stylists separately, protecting brand equity from isolated staff mistakes.

B. Live Pitch Script for Zonal Managers & Franchise Admins

  • Territorial Integrity: Log in as Zonal Manager (manager.ramnad@stylebook.com) to demonstrate that they only see and approve salons in South Zone (Ramanathapuram).
  • Instant Governance Toggles: Flip a branch or stylist to "Inactive" and immediately show the customer portal auto-refreshing to remove the unverified shop.
  • Downgrade Provisioning Security: Show that managers can safely provision shop owners and stylists without being able to compromise state or super-admin tiers.
  • Direct Help Desk POCs: Point out the structured contact directory for Store Operations, Regional Administration, and Accounts & Billing.

C. Live Pitch Walkthrough for End Customers (B2C)

  1. Landing Page Smart Search: Type "Karthik" or "Bridal" or "Puduvalasai" to showcase real-time multi-dimensional search.
  2. Dynamic Carousels: Glide through Trending Salons, Top-Rated Branches, and Top-Rated Stylists.
  3. Choose Branch vs. Choose Stylist: Walk through both booking paths to highlight convenience.
  4. Coupon Code RAMNAD50: Apply promo code on checkout to demonstrate instant ₹50 savings.
  5. WhatsApp Notification Simulation: Display the on-screen simulated WhatsApp dispatch with arrival OTP.
  6. Dual Rating Submission: Open My History on a completed booking and submit separate 5-star ratings for the branch and stylist.
